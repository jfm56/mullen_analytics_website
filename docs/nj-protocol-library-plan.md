## 3. Architecture (separate, versioned clinical-protocol layer)
Kept entirely separate from the CQI library + scoring.

**Data model (new tables, feature-flagged `NJ_PROTOCOLS_ENABLED`, default off):**
- `clinical_protocol_sets` — a jurisdiction+version (e.g. `NJ / v1 / 2025-08-21`), with `source_document`, `source_url`, `issuing_authority`, `effective_date`, `retired_date`.
- `clinical_protocols` — one row per protocol per set: `identifier` (e.g. `3.0`), `title`, `chapter`, `source_page`, `credential_applicability` (BLS/ALS/CF/A-B/Pediatric), `standing_order` vs `medical_command`, `category` (cardiac/trauma/respiratory/refusal/stroke/overdose/OB/…), `pediatric` flag, `text_excerpt` (verbatim, citation-bound), `version`, `effective_date`.
- `protocol_indications` / `protocol_contraindications` — structured, per protocol+credential, each with a source citation.
- `clinical_protocol_versions` — **full history**; a protocol is never edited in place, a new version row is added, so **a chart is reviewed against the rules in effect on its date of service**.
- `agency_protocol_config` — per agency: `jurisdiction`, `protocol_set_id`, `medical_director_approved_version`, `adopted_at`, `waivers`/`supplemental` (agency-specific, MD-approved). **Non-NJ agencies get no NJ rules.**
- `cqi_protocol_map` — links an EMSCS CQI indicator to the NJ protocol(s) that inform it (many-to-many), with a `relationship` note. **Documentation scoring stays in the CQI tables; clinical-protocol findings are a separate output.**

**Version selection at review time:** pick the protocol set = agency jurisdiction + the MD-approved
version effective on the chart's date of service (historical preservation).

**Clinical decision support (conservative, as specified):**
- Deterministic checks only for clearly documented, unambiguous facts (e.g. "NTG given with documented SBP 86" → apparent deviation).
- **HUMAN_REVIEW_REQUIRED** for uncertain indication/contraindication, clinical appropriateness, or conflicting evidence.
- **No automatic finding of malpractice/negligence or definitive protocol violation**; findings are "apparent deviation — clinical review", never adjudications.
- **No invented requirements**; every rule cites a protocol + page + version.

## 5. Clinical ambiguities (need EMSCS/medical-director decisions)
1. **Oxygen threshold 92% vs 94%:** CQI #24/#37 rubric says <92%; NJ says <94% (target ≥94%). Currently the gray zone (92–93%) routes to human. **Decide:** align the CQI threshold to NJ, or keep 92% for documentation scoring and treat NJ as a separate clinical finding?
2. **COPD oxygen titration:** NJ gives a baseline goal >90% but it is patient-specific → currently human review. Encode deterministically only if EMSCS provides a bright-line rule.
3. **ASA/NTG indication ("likely ACS"):** NJ requires clinical judgment of ACS likelihood → indication uncertainty routes to human; confirm the structured fields EMSCS wants captured (risk factors, 12-lead).
4. **SMR indication:** relies on a documented spinal assessment (NJ §6.0); confirm EMSCS wants a dedicated structured "spinal assessment documented + result" field.
5. **Standing-order vs medical-command** boundaries differ by credential and by agency MD adoption — must be agency-configured, not assumed.
6. **Pediatric vs adult** thresholds differ (e.g. SBP, TBI) — pediatric protocols are a distinct set.

## 6. Implementation plan (phased; approval gate before any evaluator activates)
1. **Inventory (committed, deterministic):** `scripts/nj_protocol_inventory.py` → a versioned JSON of all protocols (number/title/page/tier/standing-order/pediatric). Review for accuracy. *(No clinical logic.)*
2. **Schema + seed (flagged off):** the tables above; seed the NJ v1 set + agency config; **no evaluator wired.**
3. **CQI↔protocol map + Protocol Library UI (read-only):** searchable library for agency reviewers + Super Admin, with source citations + version history. *(Reference only — no findings yet.)*
4. **Conservative clinical findings (opt-in, per approved mapping):** start with the already-verified Cardiac #24/#27 + Trauma #37/#38 as the template; expand only to protocols with a clear deterministic fact + human review for the rest. Each finding cites protocol+page+version; findings are separate from CQI scoring.
5. **Agency adoption + historical review:** date-of-service version selection; MD-approved version per agency.

**Deliverables already provided for approval:** this inventory + architecture + CQI mapping + ambiguities
+ plan. **Nothing is built or activated until approved.** The three NJ-verified safeguards (oxygen,
ASA/NTG, SMR) in `emscs-qa-clinical-safeguards-report.md` are the conservative template.
